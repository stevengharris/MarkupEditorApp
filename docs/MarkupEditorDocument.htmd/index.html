The MarkupEditor Document

The MarkupEditor is an application for creating and editing HTML documents. As you edit the document, you may want to insert images from files you have available locally, or paste images into the document. When you do so, the image itself will be placed in a separate file that needs to be packaged with the HTML document. To handle this packaging problem, the MarkupEditor uses a custom Uniform Type Identifier that defines an htmd package as a directory that contains a single .html file and the local resources it references. This package shows up on the file system as a single .htmd file, so you can copy and move the document along with the local resources it references as a single file.

Document Structure

  1. The htmd package must contain a single .html file at its root which we will refer to as the root html. By default, the root html will be index.html, but it can have any file name that has an html extension.

  2. All image files identified in the root html using an HTML Image Embed element should be present at the root or below of the htmd package. (Technically, the src element of a local image uses a sub-resource URL.)

  3. Image files that are present in the root but which are not present in any HTML Image Embed element of the root html may be deleted. For example, to avoid unnecessary document bloat, the MarkupEditor app deletes all images at document save time that are not referenced within the root html.

  4. The root may contain other MarkupEditor documents, with extension .htmd.

  5. The root may contain XML metadata files, with extension .data.

  6. The root may contain CSS files, with extension .css.

HTML <-> Markdown

The MarkupEditor HTML content restrictions mean that when you create or edit a MarkupEditor document, it can be exported to Markdown with no loss of content or formatting. Everything you write or format in the MarkupEditor will be present in the Markdown file in the Markdown-equivalent of the HTML. If you import that Markdown file back into the MarkupEditor, it will appear exactly as it did when you exported it. Thus, if you use the MarkupEditor to edit, you can always round-trip between what you see in the MarkupEditor and a Markdown form. When you see a .htmd file, you know that it is losslessly transformable between HTML and Markdown.
