## Instructions

Fill in the front matter above as needed, write the post below, and delete this section and the horizontal rule below it before publishing.

* **title**: The post title. *Recommendation*: Start your post with a `#` heading, and leave the `title` metadata blank. That heading will be the `title`. Only a heading at the very start of the post counts, and only a `#` (level 1) heading.
* **slug**: The last part of the post's URL, such as `my-post` for `/blog/my-post/`. It is cleaned to lowercase letters, digits and hyphens. Left empty, it comes from the file name. Slugs should be unique. *Recommendation*: Leave `slug` empty. Keep every post in its own folder, named for the post, inside one blog directory. The file system then keeps names unique.
* **tags**: A list, such as `[release, notes]`. A tag that does not exist yet is created, so spell them consistently.
* **excerpt**: A short summary, at most 300 characters.
* **meta_description**: The description for search results and social sharing.
* **feature_image**: The file name of the banner image for the post, or a full `https://` address.
* **feature_image_alt**: Alt text for the feature image.
* **date**: Optional. The date shown on the post, such as `2026-11-20`. *Recommendation*: Leave `date` empty to use the date the post is published.

Save the post as `<slug>/<slug>.md` in a folder, with its images in the same folder, and refer to them by file name. By default, MarkupEditor saves local images you add to a post in the same folder as the post.
