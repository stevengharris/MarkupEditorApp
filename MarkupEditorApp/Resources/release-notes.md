This is the Beta 3 release. It is a quick follow-on to 0.9.12 that handles Beta versions properly and allows users to re-evaluate the product as major/minor versions advance.

* Identify Evaluation Beta releases and a limited time window for them. An Evaluation Beta shows "Beta" in its version and in the About window.
* A new Evaluation Beta, or an Evaluation version with a higher major or minor number, restarts the evaluation period, so you can try it after an earlier evaluation has ended.
