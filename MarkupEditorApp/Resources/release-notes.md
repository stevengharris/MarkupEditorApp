This is the Beta 4 release. It adds task lists to Markdown documents and lets you run your own Shortcuts from within MarkupEditor.

* Task lists. A list item that begins with `[ ]` or `[x]` in a Markdown document shows as a checkbox that you can click to check and uncheck. Press Enter in a task item to start a new unchecked task, and Backspace at the start of its text to remove the checkbox. Markdown files keep their task list syntax when you save, as `[ ]` and `[x]`. A task list you edit is saved with `*` bullets.
* Shortcuts. Choose Shortcuts from your Shortcuts library in the Tools tab of the side panel, then run one on the open document from File > Run Shortcut, so you can automate publishing or other steps with the tools you already use.
* A fix to a priority warning that macOS 27 reports when MarkupEditor reads your Shortcuts library.
